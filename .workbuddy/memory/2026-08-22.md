## 修复：dsh 启动报错 "result codec is not backed by a zod v4 schema"（v1.1.2）

- **根因**：typert-loader（@deepseek-ai/dsh-typert-loader）在 `requireStrictCodec` 中要求 codec.schema 必须是 zod **v4** 实例（检查 `_zod` 标记 + `.parse` 函数）。而 monorepo 根与 `packages/dsh-money/package.json` 声明的是 zod **v3**（`^3.25.76` / `^3.24.1`），导致生成的 `lib/typert.host.js` 里 `import { z } from 'zod'` 运行时解析到 v3 schema（无 `_zod`），`dsh-money#moneyCost/balance` 结果 codec 校验失败，插件树整体加载失败。
- **修复**：两处 package.json 的 zod 依赖升级为 `^4.4.3`（与 dsh-typert-generator / loader / registry 一致），`npm install` 后全树 dedupe 到 `zod@4.4.3`；`npm run build` 重新生成 typert 产物；用脚本模拟 loader 校验逻辑验证 4 个 invocation（balance/config/overview/workspacesAll）全部通过。
- **注意**：lib/ 在 .gitignore 中，生成产物不提交；本次改动仅 package.json / package-lock.json / README.md。
- README「故障排查」新增该报错的处理行；「开发」章节注明依赖要求 zod v4。
- 提交 7230bda + tag v1.1.2，已 push origin main（走全局代理）。

## 修复：web boot 报 "dsh-money: pending (waiting for service: remote.moneyCost)"（v1.1.3）

- **根因**：客户端 `remote.<namespace>` 服务（如 `remote.moneyCost`）**必须由客户端插件显式 `ctx.remote.$mount(contribution)` 挂载后才存在**（无 host 自动同步，见 `dsh-api-gateway` client 的 `mountContribution`/`createNamespace`，以及 cordis `getTraceable` 按 `remote.<ns>` 点号键解析）。旧版 client bundle（client.static.js 直接打包）只声明 `inject: ['slots','remote','remote.moneyCost','timer']` 却从未挂载，导致注入死锁。
- **修复**（esbuild 聚合打包 client，与 dsh-api-remotes 同构）：
  - 新增 `src/client.entry.js`：esbuild 入口，`inject = ['slots','remote','timer']`（去掉 remote.moneyCost），async apply 先 `await ctx.remote.$mount(TYPERT_REMOTE)` 再委托 client.static.cjs 的 UI 逻辑，返回组合 disposer。
  - `src/client.static.js` → **`src/client.static.cjs`**（包 `"type":"module"` 下 esbuild 会把 .js 当 ESM，CJS 的 module.exports 不被识别；.cjs 后缀解决）；inject 同步去掉 remote.moneyCost。
  - `scripts/build.mjs` 第 3 步改为 esbuild bundle（bundle:true / format cjs / platform browser / external react / write:false），zod v4 schema 内联进 lib/client.js（约 580KB）。
  - 清理死代码：`src/client.js`、`src/host.js`、`src/types.d.ts`（静态化前的旧实现，均未被 tsconfig/构建引用）。
- **验证**：冒烟测试——模拟 window.__ModuleLoader__ + mock react 加载 lib/client.js，module.exports={apply,inject}，inject 正确，apply 调用 $mount 且贡献含 4 个 descriptors。
- 关键机制备忘：cordis 服务点号访问 `ctx.remote.moneyCost` 依赖 `remote.moneyCost` 服务注册后由 getTraceable 代理解析（`tracker.associate + '.' + prop` 查 reflect.props）。
- 提交 22bc9bb + tag v1.1.3，已 push origin main。
